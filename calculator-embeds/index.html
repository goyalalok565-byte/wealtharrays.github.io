Example embed code

For the break-even demo, add this iframe where you want the calculator to appear. Replace break-even with a supported calculator ID to preview another tool.

<iframe
  src="https://wealtharrays.com/widget/?calc=break-even"
  title="Break-even calculator"
  width="100%"
  height="760"
  loading="lazy"
  referrerpolicy="strict-origin-when-cross-origin"
  style="border:0;width:100%;">
</iframe>

Change the calculator above and copy its matching snippet. Test the embed on your own mobile and desktop layouts before publishing it; adjust the height if your page needs more room.

Frequently asked questions

Does the demo require a login?

No account is needed to use the public demo.

Can I change the calculator?

The widget supports calculator selection through its URL. Custom behavior or branding is reviewed separately before it is promised.

Can you guarantee a specific revenue or conversion lift?

No. A calculator can add utility to a page, but audience response and business outcomes depend on your traffic, offer and implementation.

Is the API the same as the browser calculator catalogue?

No. API model coverage is smaller than the browser calculator catalogue. API access and any integration require a separate technical and commercial review.
