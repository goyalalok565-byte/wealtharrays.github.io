ROI vs Annualized Return: Formula, Limits and Examples

Return on investment (ROI) is a simple way to describe the gain or loss relative to the original cost. It becomes less useful when you compare investments held for different lengths of time, because a 20% gain over one year is not equivalent to a 20% gain over five years.

Written and maintained by Wealth Arrays. Last reviewed: September 14, 2026.

Basic ROI

Simple ROI is (final value − initial cost) ÷ initial cost × 100. If ₹10,000 becomes ₹12,000, the total ROI is 20%. This number describes the total change over the period; it does not say how quickly the change happened.

Why time matters

To compare growth across different holding periods, an annualized measure such as CAGR can be more informative. CAGR asks what constant annual rate would mathematically turn the starting value into the ending value over the stated period. It is a smoothing measure, not a description of the actual path.

ROI can hide cash-flow complexity

Simple ROI is not enough when there are multiple deposits, withdrawals or irregular cash flows. In those cases, a money-weighted measure such as IRR or XIRR may answer a different question. Do not label every return percentage as “ROI” when the underlying cash flows are more complicated.

Costs and taxes matter

A headline return can be reduced by transaction costs, management fees, taxes or other charges. When comparing real outcomes, use consistent after-cost or after-tax assumptions. A calculator that does not model those items should say so rather than implying precision it does not have.

Practical comparison

Use ROI for a quick total-gain view. Use CAGR when you need a normalized annual growth comparison for a single starting value and single ending value. Use cash-flow-aware methods when contributions or withdrawals occur throughout the period.

Common mistakes

  • Comparing ROI percentages without checking the holding period.
  • Ignoring fees and taxes.
  • Calling a volatile path a constant annual return.
  • Using CAGR when there are many irregular cash flows.
