INVESTING · RETURNS

How to Read an Investment Return Number Correctly

Written and maintained by Alok Goyal, founder and creator of Wealth Arrays. This guide is educational and not personalised financial advice.

A percentage labelled “return” can mean several different things. A 30% gain over one year is not the same as a 30% gain over five years, and a simple percentage gain can be misleading when money was added or withdrawn during the period. Before comparing investments, identify exactly what the percentage measures.

Start with the simplest case

If you invest ₹1,00,000 and later have ₹1,30,000 with no additional contributions or withdrawals, the absolute gain is ₹30,000 and the simple return is 30%. That calculation is useful when the starting and ending values are clear and there are no intermediate cash flows.

The ROI Calculator can perform this basic percentage calculation. But ROI does not automatically tell you how quickly the money grew.

Holding period changes the meaning

A 30% return over one year and a 30% return over five years describe very different growth rates. To compare multi-year growth on a common annual basis, an annualized measure is more informative.

CAGR is one such measure when there is a single starting value, a single ending value and a defined holding period. The formula is:

CAGR = (Ending value ÷ Starting value)1/years − 1

The CAGR Calculator can convert the multi-year change into that equivalent constant annual growth rate.

CAGR is a smoothing calculation

CAGR does not claim that the investment actually earned the same percentage every year. It describes the constant annual rate that would mathematically turn the starting value into the ending value over the stated period.

An investment could fall sharply in the first year and recover later, or rise quickly and then stagnate. Two investments with the same beginning and ending values can therefore have the same CAGR while having very different paths and risks.

Intermediate cash flows create another problem

Suppose you invest ₹1,00,000 initially, add ₹20,000 later, and eventually withdraw ₹10,000. Comparing only the first deposit with the final account value ignores the timing of those cash flows. The money was not invested for the same length of time.

For irregular contributions and withdrawals, use a return method designed for cash-flow timing, such as an internal-rate-of-return approach, when the necessary dates and cash flows are available. Do not force a simple ROI formula onto a cash-flow pattern it was not designed to describe.

Do not compare percentages without checking what is included

One return figure may be before fees and taxes while another may be after them. One may include dividends or interest while another uses only price appreciation. One may be nominal while another has been adjusted for inflation.

Write down the definition before comparing two numbers. Ask: Is it gross or net? Is it nominal or inflation-adjusted? Does it include income distributions? What is the holding period? Were additional amounts invested?

Return is not the same as risk

A historical return tells you what happened under a particular path. It does not by itself tell you how likely the same result is to repeat. A smooth return and a volatile return can produce the same ending value, but the investor experience can be very different.

When using a calculator for planning, treat an assumed return as an input, not a promise. Test a lower assumption and compare how strongly the result changes.

A practical comparison framework

  1. Identify the starting amount and ending amount.
  2. Check whether there were contributions or withdrawals.
  3. Record the exact holding period.
  4. Determine whether the percentage is ROI, CAGR, annualized return or another measure.
  5. Check whether fees, taxes and income distributions are included.
  6. Check whether inflation adjustment is relevant.
  7. Compare multiple scenarios rather than selecting the highest percentage.

Worked interpretation

Imagine Investment A grows from ₹2 lakh to ₹3 lakh over three years with no cash flows. Investment B also grows from ₹2 lakh to ₹3 lakh over three years. Their CAGR is mathematically identical, even if A experienced a large decline in year two and B grew steadily. The return number answers the growth question, not the path question.

If you were choosing between the two using only the ending balance, you would be ignoring information that the return percentage does not contain. This is why calculators should be used alongside the underlying statements and product information.

Bottom line

A return percentage is only meaningful when you know the definition behind it. ROI can describe a gain relative to the starting amount; CAGR can normalize a multi-year start-to-end change; cash-flow-aware methods can handle irregular contributions and withdrawals. Check the holding period, cash flows, fees, taxes and inflation before comparing numbers.
