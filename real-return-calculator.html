What is a real return?

A nominal return is the growth rate before adjusting for changes in prices. A real return accounts for inflation, which helps answer the more useful question: how much purchasing power did the investment actually add?

The Fisher relationship

This calculator uses the exact relationship real return = (1 + nominal return) ÷ (1 + inflation) − 1. For small percentages, subtracting inflation from the nominal return is a useful approximation, but the exact formula is preferable when comparing meaningful rates.

Why purchasing power matters

A balance can rise substantially while its purchasing power rises much less. Looking at both nominal and inflation-adjusted values helps avoid treating future currency amounts as if they were today's money.
