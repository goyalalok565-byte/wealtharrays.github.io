See how your money could grow over time.

Use this page to make a simple long-term savings plan. Enter what you have, what you can add each month and how long you can save. We estimate the possible result and show how it changes under different assumptions.

Start here — no expert knowledge needed

  1. Enter your current savings and the amount you can add each month.
  2. Choose an estimated yearly return, inflation rate and number of years.
  3. Press Calculate my plan to see the estimate below.
  4. Use Save on this device to return later on this same browser.

Important: Returns are assumptions, not promises. Your saved plan stays in this browser; it does not sync to other devices.
