# Privacy-first product contract

Default principle: calculations run in the browser and do not require an account. Financial Workspace currently supports local browser save/load/delete via localStorage; saved inputs are not sent to a Wealth Arrays server by this feature.

Before adding saved financial workspaces:
- collect only data necessary for the requested feature;
- obtain appropriate consent before non-essential analytics;
- provide export and deletion controls;
- never expose saved financial data to advertising systems;
- document retention periods and processors;
- keep country/tax data separate from personal financial data;
- provide a clear offline/local-only mode where practical.

Analytics must measure product behaviour without storing raw financial inputs unless explicitly required and consented to.
