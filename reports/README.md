# Reproducible Financial Report Contract

Future Wealth Arrays reports should contain:
1. Tool/model name and version.
2. Input values and currency.
3. Calculation date.
4. Assumptions and timing conventions.
5. Formula/model identifier.
6. Scenario definitions.
7. Results in nominal and, where applicable, today's-money terms.
8. Stress-test cases used.
9. Source provenance for jurisdiction-specific rules.
10. Limitations and educational disclaimer.

A report must be reproducible from the recorded inputs, model version and assumptions. AI-generated prose may explain a report but must never replace the underlying deterministic result.
