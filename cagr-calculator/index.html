What this calculator does

Calculate the compound annual growth rate between a starting and ending value. The result is generated locally from the values you choose, so the most useful way to use the tool is to test realistic assumptions instead of looking for a single “correct” future number.

Good financial planning is usually a range exercise. Try a conservative scenario, a middle scenario and a stressful scenario. The comparison feature is intended to make those trade-offs visible without opening separate calculators.

How the calculation works

CAGR = (Ending value ÷ Starting value)^(1 ÷ years) − 1. It converts a multi-year change into an equivalent constant annual growth rate.

The formula is deliberately transparent because a calculator should explain the logic behind the answer. A precise-looking number is not automatically a precise prediction: the mathematics can be correct while the assumptions are unrealistic. Keep those two ideas separate.

How to use the result responsibly

CAGR is useful for comparing two endpoints, but it hides volatility and interim cash flows. A portfolio that moved from ₹1,00,000 to ₹1,61,051 could have taken a very different path from another investment with the same CAGR.

Do not use CAGR as a forecast. If there were deposits, withdrawals, dividends or other cash flows during the period, use a return method designed for those cash flows and keep fees and taxes explicit.

Worked scenario

Use ₹1,00,000 as the starting value, ₹1,61,051 as the ending value and 5 years. The calculator returns a CAGR of about 10.00%. Now imagine the investment fell sharply in year 2 and recovered later: the CAGR would still only describe the start and end points. For investments with contributions or withdrawals in between, use a cash-flow-aware return measure instead of relying on CAGR alone.

Limitations and methodology

Wealth Arrays uses deterministic formulas: identical inputs produce identical outputs. Real-world outcomes may differ because financial products can use different day-count conventions, compounding schedules, payment timing, fees, taxes, rounding rules and eligibility conditions. Where a country-specific rule matters, a generic calculator should not pretend to know it.

This page therefore presents the result as an estimate for education and planning. Check official documents and current rules before taking action based on a calculation.

Frequently asked questions

Does CAGR mean the investment earned the same return every year?

No. It is a smoothed equivalent rate, not the actual yearly path.

Can CAGR be negative?

Yes. An ending value below the starting value produces negative CAGR.

Can I calculate CAGR from zero?

No; the starting-value denominator makes the ratio undefined.

Does CAGR include cash flows added during the period?

Not correctly for irregular contributions; use an appropriate money-weighted or time-weighted return method.

Does CAGR predict the future?

No. It summarises past start/end values only.

Overview and scope

Compound annual growth rate (CAGR) expresses the constant annual rate that links a starting value to an ending value over a stated number of years. It smooths the path into one annualised number; it does not show volatility or the sequence of gains and losses. It is useful for comparing growth periods only when the start, end and time basis are defined consistently.

Calculation method and assumptions

CAGR = [(ending value ÷ starting value)^(1 ÷ years) − 1] × 100. The formula requires a positive starting value, positive ending value and positive duration. CAGR is undefined when the starting value is zero.

Additional worked examples

  • Value rises from ₹100,000 to ₹160,000 over 5 years: CAGR ≈ 9.86% per year.
  • Value rises from ₹250,000 to ₹400,000 over 4 years: CAGR ≈ 12.47% per year.

Common mistakes to avoid

Do not use CAGR for a series with substantial interim deposits or withdrawals unless the method accounts for cash flows. Do not ignore dates, fees, taxes, dividends or volatility. Avoid comparing periods with different lengths without annualising them consistently.
